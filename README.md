# 企业 AI 业务工作台 · V0.2

企业研发 AI 平台的统一门户和应用注册中心。平台登记四个业务方向：**问题经验 / 项目管理 / 标准化与优选件 / 质量决策助手**。

三个业务板块现均提供可操作的本地试点：**问题经验**支持 Excel 导入、规则校验与台账；**项目管理**支持项目组合、DCP 里程碑、风险闭环与 Markdown 周报；**标准化与优选件**支持物料目录、相似件文本检索、BOM 规则校验和历史追溯。`problem-hub` 与 `pm-platform` 继续独立部署，可通过环境变量配置跳转；门户本地试点数据不会自动同步到外部系统。质量决策助手仍属规划项。

> 边界说明：本项目是**新建的统一工作台**，不修改、不覆盖工作区中已有的两个独立系统
> （`../1.AI+问题经验/problem-hub`、`../2.AI+项目管理/pm-platform`）。
> Excel 识别的业务口径（同义词词典、置信度分级、严重度枚举）沿用 problem-hub 已验收规则。

## 一、如何启动

环境要求：macOS / Linux，Python 3.11+（本地试点使用 SQLite，无需另装数据库）。

**方式一：一键脚本**

```bash
bash run.sh
```

**方式二：手动启动**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt          # 网络慢可加 -i https://pypi.tuna.tsinghua.edu.cn/simple
.venv/bin/uvicorn backend.app.main:app --port 8088
```

启动成功后访问：**http://127.0.0.1:8088**

数据文件位置：`data/workbench.db`（模拟问题库）、`data/uploads/`（上传的 Excel 原件）。

## 二、Excel 导入功能如何操作

1. 左侧导航进入「**问题经验**」→「**Excel 导入**」页；
2. 没有文件可先点「**下载演示样本**」（样本内含正常行、缺必填行、非法枚举、错误日期、同义表头）；
3. 点击上传区或把 `.xlsx` 拖入（≤20MB）。系统会：
   - 自动识别工作表（多个表时推荐最像问题清单的表，可手动切换）；
   - 自动识别表头并映射到 12 个问题库字段，**列顺序不限**；
   - 高置信（同义词精确命中）直接采用；模糊命中标黄色「**待确认**」；无法识别标「未映射」；
4. 在「**字段映射**」区可逐列手动改选目标字段，改完即时重新解析；
5. 在「**数据预览**」区：
   - 🔴 红底 = 错误，**必须修改或剔除**该行才能入库（必填缺失、严重度非 A/B/C）；
   - 🟡 黄底 = 警告（如日期无法识别，会置空后入库）；
   - 可直接点击单元格修改，可勾选「剔除」跳过整行，可用「只看有问题的行」快速定位；
6. 点「**确认导入**」→ 错误行被拒绝并在结果页逐条列明原因，其余行写入模拟问题库；
7. 「**问题台账**」页可搜索、按严重度/批次筛选、分页查看；「**导入历史**」页可查看批次、继续处理待确认批次。

防呆机制：非 xlsx / 损坏文件直接拒绝（中文错误提示）；同一批次重复提交返回 409；
默认开发试点按完整业务内容计算行指纹；生产必须由业务负责人配置 IMPORT_DEDUPE_POLICY（content 或 row_instance），明确相同内容是否视作重复；猜测值永远不会被静默写入（非法枚举保留原值并报错）。

## 四、三个业务板块的试点能力

- **问题经验**：Excel 上传、工作表/表头识别、手动映射、校验、异常剔除、导入历史、台账检索。
- **项目管理**：项目新增/编辑、阶段与进度、DCP 节点、风险等级/责任人/到期日、风险关闭、组合指标及 Markdown 周报导出。
- **标准化与优选件**：物料档案新增/编辑、优选件标记、生命周期管理、文本相似度检索、BOM 逐项合规判断、替代优选件建议和历史检查记录。
- 两个新增业务板块的数据存储在本地试点数据库；相似件为确定性文本匹配而非大模型结论。正式接入 PLM/QMS/独立项目管理系统前，仍需对接契约、权限、审计及业务验收。

## 五、实际运行的测试

- 单元/接口测试：`python -m pytest backend/tests -q`
- 结果以当前分支 GitHub Actions 为准；新增覆盖项目管理接口、DCP/风险生命周期、物料目录、相似件检索、BOM 校验规则及历史查询。
- 真实样本端到端冒烟（curl）：9 行识别 → 2 行错误被拒并给出原因 → 7 行入库 →
  重复提交 409 → 台账/历史/首页计数一致。
- 语法门禁：`PYTHONPYCACHEPREFIX=/tmp/workbench-pycache .venv/bin/python -m compileall -q backend` 通过。
