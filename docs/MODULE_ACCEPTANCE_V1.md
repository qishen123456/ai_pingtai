# 三个业务板块 V1 试点验收说明

更新：2026-10-09。本文区分“本地可操作的功能”与“尚未对接的企业系统”，避免把试点描述成正式生产系统。

## 1. AI + 问题经验

- 上传 Excel，识别工作表/表头，允许人工映射、逐行校验、编辑和剔除。
- 确认后写入本地问题台账；可检索记录、查看导入批次和失败原因。
- QMS 写入、用户权限和跨系统同步未实现。

## 2. AI + 项目管理

- 项目组合：编号唯一、名称、产品线、负责人、阶段、状态、计划起止日、进度；支持新增、编辑和查询筛选。
- DCP：DCP0-DCP5 节点，计划日期、负责人、备注、待办/通过/阻塞状态；标记通过时自动记录实际日期。
- 风险：高/中/低等级、责任人、截止日期、措施和开放/跟踪/已解决状态；组合指标显示未关闭风险和逾期风险。
- 报告：前端将当前本地项目、DCP 和风险信息导出为 Markdown。
- 独立的 pm-platform 仍单独部署；设置 PM_PLATFORM_URL 后导航跳转它。本地试点数据不会自动同步过去。

## 3. AI + 标准化与优选件

- 物料目录：编码唯一、名称、规格、分类、制造商、生命周期、优选件标记、替代编码和备注；支持新增、编辑、筛选。
- 相似件检索：确定性文本相似度和字段命中理由，显示排序分值；不伪称大模型语义结果。
- BOM：逐项匹配本地物料档案，区分优选合规、非优选待复核、待审核、停用和未登记编码；对不合规项推荐有效优选件，保存历史检查记录。
- PLM 只读/写回、BOM 真实模板适配和企业级同义/规格工程规则未实现；替代建议须工程师复核，不能作为量产放行结论。

## 公共限制

- 本地数据库仅用于单环境试点；暂未实现登录/SSO/RBAC、多租户、操作审计和正式数据库迁移流程。
- 真实数据接入前需要业务负责人确认字段、枚举、权限、连接方式、错误处理和验收样本。
- 测试命令：python -m pytest backend/tests -q；JavaScript 语法检查由 .github/workflows/tests.yml 执行。
