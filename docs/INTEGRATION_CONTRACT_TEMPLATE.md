# 外部系统接入契约模板（每接一个系统复制一份）

> 当前这是交接模板，不代表系统已连通。不要在缺少接口文档、测试环境或审批的情况下打开写回开关。
> 可复制为 docs/integrations/QMS.md、PLM.md、problem-hub.md、pm-platform.md 或 model-gateway.md。

## A. 责任人和范围

- 系统名称/环境：待填写
- 业务 owner、IT owner、安全审批人：待填写
- API 文档链接、版本、更新时间：待填写
- 测试/预发布/生产地址：待填写
- 接入目标（只读/双向写入/事件订阅）：待填写
- 当前适配器状态：not_implemented（在代码和测试验收前不得改成已接入）

## C. 身份和网络

- 认证方式（OAuth2 client credentials / mTLS / signed webhook 等）：待填写

- 所需 scope/角色/最小权限清单：待填写
- TLS 校验、证书轮换、源 IP / 网络策略：待填写
- 个人信息、商业机密、模型输入数据分类：待填写
- 日志是否可存业务字段，脱敏/保留策略：待填写

## G. 生产启用条件

只有在接口契约、凭证权限、测试数据、幂等/重试/冲突方案、数据分类、审计和回滚均验收后，才允许将该连接从 not_implemented 改为已实现。仅填 URL、能连通 TCP 或健康检查返回 200，不足以证明业务集成成功。
